### Hi, I'm Zsolt 👋

I build **[LCD Ultra Pro](https://lcdultrapro.com)**, a visual LVGL editor for ESP32 display boards that runs in the browser.

You pick your exact board, design the screens, and export an Arduino project that already has the display and touch driver for that board in it. No hunting for init sequences, pin maps or `lv_conf.h` settings.

![LCD Ultra Pro editor with USB Live](https://lcdultrapro.com/videos/usb-live-demo-poster.jpg)

**What it does**

- 101 ESP32 display boards to design for, 60 of them with a driver ready in the export
- LVGL 8.4 drawing the canvas (compiled to WebAssembly), LVGL 9 on the way
- Rules for buttons, screens, timers, GPIO, sensors and MQTT, tested in the browser before you flash
- USB Live: the real display follows your edits on supported boards

**Free stuff, even if you never use the editor**
